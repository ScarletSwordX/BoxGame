# 关卡编辑器使用说明

入口：Unity 菜单 `Tools > 规则工坊 > 关卡编辑器`。L01 的实际独立地图使用 `Tools > 规则工坊 > L01 独立地图 > P1（7×3）/ P2（7×7）/ P3（12×10）` 分别打开。L02 使用 `Tools > 规则工坊 > L02 地图原型 > P1/P2/P3` 打开。两关独立地图窗口上方均可切换“游玩阶段”。旧“L01 三阶段灰盒”入口兼容打开独立 P1；菜单快捷打开使用新窗口，不覆盖未保存工作。

## 搭建前的设计要求

关卡支持可变数量的阶段：每阶段是一张独立地图，例如 `L1P1.json`、`L1P2.json`。各地图分别保存边界、地形、物件、词牌、出生点、教学提示和参考解。设计卡需逐阶段列出目的、地标与地形变化及原因、连接口、重布差异、旧目标处理及验证依据。游玩阶段数量按各关需要确定；游戏目录可配置有序阶段数组，已支持胜利后自动推进。

新增或重做关卡先执行 [关卡设计工作流](LEVEL_DESIGN_WORKFLOW.md)，使用 [设计卡模板](templates/LEVEL_DESIGN_CARD.md) 依次记录定位与目的、空间结构与地图尺寸；第 3 步搭建逐阶段地图原型并输出 JSON，再审查教学方法与反馈、解题逻辑，验证解法、盲测和定稿。原型可依据审查结果回修。Teach–Test–Twist 在多关卡联合审核时检查，不作为逐关搭建门槛。

下文说明编辑器操作，不替代阶段审查。编辑器当前没有设计阶段审批或自动门禁；可保存草稿不代表教学设计已经通过。参考解回放通过后，仍需固定视角可读性检查与非设计者盲测，才能判断玩家是否学会。

## 阶段编辑继承

在“阶段地图”面板点击“建立 / 升级整组继承（右上角对齐）”，建立 P1 → P2 → P3 → …。先保存当前地图；关联组按正式目录顺序，未发布地图按同目录 LxPy 编号排序。不会自动改动其他关卡组。

- 保存父阶段时自动更新子阶段及后续后代；保存 P2 不会反向改变 P1。撤销/重做后再次保存，同样向后传播。
- 继承范围为地图边界、地形格、物体与词牌。实体通过 ID 对应，各字段分别覆盖；修改位置不会阻断该实体其他字段的继承。地形按格和外观比较，不依赖地形长方体的编号。新版关系以各地图右上角为原点比较 X/Z；不同尺寸地图的相同编辑坐标对应同一继承位置，Y 高度不变。实体仍通过 ID 对应，其位置使用新编辑坐标。
- 建立关系时，各阶段已有差异成为局部覆盖；之后子阶段新增、移动、改属性、删除内容均保留。局部覆盖优先，即使父阶段后来碰巧改成相同值，覆盖关系也不丢失。父阶段删除已被子阶段修改的实体时，保留子阶段的完整实体。
- 地图 ID、名称、提示、参考解、镜头和玩法配置由各阶段独立保存。继承造成布局变化后，已有参考解标为待重新验证。
- 一次保存按阶段顺序计算继承。继承落点被占或越界时保留子阶段原位置、跳过冲突的新增地块或实体；尺寸变化会裁掉子阶段内容时保留原尺寸，其余可应用部分继续继承。跳过不形成永久覆盖，后续保存条件允许时会重试。无法解析或验证的阶段、其他窗口有未保存编辑或正在试玩的阶段整张跳过，其后代本轮不再级联；当前地图仍保存。保存提示显示跳过原因，完整明细在 Console。当前手动编辑本身仍检查地图数据与占格；实际文件写入失败仍回滚本次已写文件。
- 继承信息存入 JSON 的 `editorInheritance` 作者元数据，地图仍保存完整初态，schemaVersion 仍为 9。运行时无需读取父地图，也不继承玩家通关残局。

## 独立阶段地图

1. 完成设计卡前两道工序后，在工序 3 为各阶段分别建立原型地图文件，并按 `L1P1.json`、`L1P2.json` 一类名称区分。每张地图有自己的 bounds 和地形，可依据设计复制前阶段地图作为起点，再扩展或局部调整；边界无需逐步包含。
2. 在“关卡设置”填写对应地图 ID 和标题；文件名与 ID 建议一致，例如 `L1P1`。打开某阶段地图后编辑该阶段初态；启用编辑继承时，保存会向后续阶段传播未被覆盖的布局字段，切换地图不会带入试玩残局。移动具有 YOU 的物件来设置该阶段出生点。
3. 对每张地图分别校验和试玩。缩小地图时检查当前地图的实体、地形和教学区域；跨阶段的地标、连接口与差异依据设计卡人工复核。

### 自动关联与切换

- 打开已登记地图时，以 `Content/Levels/catalog.json` 的 `stageSequences` 显式分组与排序，L01/L02 均关联各自三张独立地图。
- 未登记草稿采用同目录完整文件名 `L数字P数字.json`，且地图 ID 与文件名一致；精确匹配关卡数字，按阶段数字排序。因此 L2 不会混入 L20，P10 排在 P2 之后，backup 后缀不参与关联。
- 上方“游玩阶段”下拉切换当前文件；未保存时提供保存、取消或不保存选择，保存失败不会切换。新文件获得独立编辑会话与撤销历史，不混写其他阶段；试玩或拖动期间禁用切换。
- “阶段地图”页可点击“刷新关联阶段”，适用于新增文件或修改目录后。刷新或切换不把试玩残局写进地图。

阶段不再靠一张地图中的区域颜色或首次开放归属表达。新地图无需 `stagePlan.regions`；旧含 `stagePlan` 的草稿可兼容读取，通过上方“旧草稿阶段”切换，在“阶段地图”页点击“导出当前阶段为独立地图”，不能继续新增阶段区域归属。

### 阶段校验、试玩与保存

- 每张独立地图分别检查初态、录制参考解并回放。编辑后重新验证相关参考解；缺参考解时可先试玩录解，正式验收仍检查规定数量。
- “开始试玩”使用已打开地图的固定初态与完整 bounds、地形和词牌。位移、变形、撤销和重开只属于当前会话，退出恢复作者初态；其他阶段地图不会提供隐藏规则。
- 旧 `stagePlan` 的 `stages`、`regions` 与 `boundaryMode` 仅用于兼容读取、旧阶段切换和当前阶段导出。导出后以独立地图的 bounds、地形、实体和参考解为准；不继续绘制区域、着色或增加旧格式的阶段归属。新独立地图继续使用 schemaVersion 9。
- 游戏运行目录 LevelCatalog 的 stageSequences 为每个关卡配置有序 maps；maps[0] 对应 levels 中的入口资源，id 为整关 ID。阶段数由数组长度决定；旧单图不必配置。正式目录仅有 L01/L02，直接引用 L1P1—P3 与 L2P1—P3 六个文件；编辑这些文件会影响游戏，无另一份布局副本。旧十二张无阶段地图不再载入正式游戏。
- 游戏中 P1/P2 获胜后自动进入下一阶段。新增地块展示扩展效果，结束后按下一阶段完整地图重建，因此局部删改也会生效；物件和词牌按固定初态重布。P3 才显示整关通关；L01 末阶段点击下一关进入 L02，L02 末阶段不循环进入旧关。阶段切换清空撤销历史，R 重开当前阶段，过渡期间暂不可操作。阶段进度尚未跨启动存档；独立编辑器试玩仍不会自动跳图。

## 编辑坐标原点（右上角 0 层）

地图画面与玩家方向保持不变。二维图右上角的 0 层格为 `(0,0,0)`，向左为 +X，向下为 +Z，Y 高度不变。三维图用青色框标记同一原点；三维镜头旋转后原点跟随地图，不随屏幕角落改变。

悬停、对象详情、坐标输入、整组偏移、区域输入和移动箭头使用上述编辑坐标。输入坐标与拖动在提交时转换为原始坐标，关卡 JSON 的实际布局、规则解析和参考解命令继续使用原坐标。`editorInheritance` 版本 2 的快照和覆盖使用新编辑坐标；版本 1 仍兼容旧坐标，可用整组升级按钮迁移。升级以各阶段当前差异重建覆盖，保留现有布局。原始校验报告中的诊断坐标仍对应 JSON。

“地图大小”固定当前右上角，增加 X 向左扩展，增加 Z 向下扩展；高度从“底层高度 Y”向上计算。应用前仍检查裁切、占格与区域。仅改变显示不会产生编辑记录、保存或继承覆盖；新版继承以各阶段的相同编辑坐标为准，并在应用时转换回子阶段原始坐标。子阶段右上角的原始位置保持固定，未覆盖的尺寸变化向左/下扩展。

## 常规地图操作

- 顶部新建、打开、保存、另存、撤销、重做。保存作者初态；未完成的草稿可以保存并重新打开。
- 默认同时显示二维 XZ 画布和独立三维预览，可以切换单视图或调整双视图比例。
- 当前 Y 指定二维层和三维绘制平面。中键拖动画布平移、滚轮缩放；三维 Alt+左键拖动旋转。
- 三维可开启贴表面放置、剖切上层、穿透选择；透明隔墙使用编辑辅助线框，便于定位世界词牌。
- 选择对象后，两边高亮同一 ID。Ctrl 点选追加；拖空白框选；拖动已选对象移动整组。详情栏可精确输入整数坐标或整组偏移。
- 同格多个对象通过选择菜单区分。复制为新 ID；编辑锁定仅防止作者误操作，不改变词牌可推性。
- 地形笔刷支持连续拖绘。地形长方体通过拖动底面和“最高 Y”指定体积；勾选挖除地形执行减法。一次手势对应一次撤销。
- WALL 作为可受规则影响的墙壁物体，三维显示为立柱与横栏；用世界词牌 WALL IS STOP 赋予阻挡，用 WALL IS PUSH 改为可推。工具栏提供准备 WALL IS STOP 句子的快捷入口。全局禁止翻越：普通方向遇到可推实体就尝试推动，推不动则停止，不再区分 Shift 模式；仅有 STOP 的墙不可推，PUSH 墙可推。此规则与关卡高度无关，原地跳跃和特殊运动规则仍独立生效。
- 物体、词牌分别选择种类与 token。“放置句子”选择“向右 +X”或“向下 -Z”，从主体名词开始放置独立词牌，预览与实际占格一致，不创建后台规则。主体必须在左/上，IS 居中，属性在右/下；反向属性句不生效。上下指二维 XZ 地图平面，同一 Y，不是世界 Y 轴；自由旋转三维镜头不会改变读句方向。
- 右侧规则来自真实解析结果；点击规则定位源词。底部问题面板显示初态、支撑和教学配置问题。
- 顶部“地图大小”直达独立面板，长度 X、高度 Y、宽度 Z 各有滑块与数字输入框，并可修改地图最小格；ID 和标题在“关卡设置”页修改。每轴 1–64 格，最大 64×64×64。点击“应用地图大小”统一提交，可撤销。缩小时若实体、地形或教学区域越界，会指出对象并拒绝修改。扩展后继续用笔刷铺设新增区域。

## 全局失控提示

所有关卡在试玩中失去可操作的 YOU 对象时，显示“没有可控制的对象了，按 Z 撤销。”。提示优先于区域教学，不需要逐关配置，失控期间持续显示；撤销或重开恢复控制后消失，正常切换控制对象不会误报。游戏 HUD 使用同一判断。

## 自动教学提示

在“教学提示”页添加提示，填写名称、正文、展示秒数，并在两种画布中绘制三维长方体区域；也可直接输入区域最小/最大格。端点包含在区域中。新提示的 5 秒只是可编辑初始值。

仅当前 YOU 进入区域会触发；初态、换控后已在区域内也触发。成功命令内的自动运动经过区域也计入，失败回滚不触发。

提示不暂停操作，按触发时间排队，同一结算点按列表顺序排队。从实际显示时开始计时，时间结束后显示下一条。入队即登记，避免重复；离开区域、撤销或试玩内重开均不取消队列或清除已触发记录。退出试玩重新开始，重置全部记录。

旧关卡的手动提示文字会保留，不猜测并自动生成触发区域；配置区域提示的关卡使用自动提示。

## 试玩与参考解

- 开始试玩会先校验初态，然后创建隔离会话。编辑器两边显示同一模拟状态，布局编辑暂时禁用。
- 点击画布后使用 WASD / 方向键移动与推动，Space 原地跳或释放弹跳顶点；Z 撤销，R 重开。玩家和试玩固定第 1 视角，编辑模式仍可自由旋转。
- 右侧操作按钮标注世界方向；键盘方向按固定第 1 视角映射。
- 退出试玩恢复原草稿、原选择、高度层和三维编辑镜头；试玩中的变形与移动不写回关卡初态。
- “参考解与回放”页可以录制新解或重录选中解。仅成功世界命令进入记录，撤销和重开同步调整路径。相机操作不计入参考解。
- 录制获胜后填写名称和策略类别，再保存。重录完成保存之前，旧解保持不变；取消录制不会覆盖旧解。
- 参考解步骤只读，可以逐步前进、后退或自动回放，不提供插入/删除命令编辑。
- 每条参考解从同一初态独立校验。任何草稿编辑使当前会话的回放结果变为待验证；不会把旧通过结果冒充新布局结果。

## 数据与边界

- 继续使用 schemaVersion 9 / RW-v0.9；自动提示存于可选字段 `tutorial.regions`。
- 不识别的设计元数据在保存时保留；禁用旧 `fixedRules` JSON 字段，包括空数组。
- 文件以 UTF-8 无 BOM、CRLF 写入；保存使用临时文件后替换，保存失败保留原文件。
- 磁盘定义、作者草稿和试玩状态隔离。保存不清空当前编辑会话的撤销历史；脚本重载会恢复草稿，但不持久化撤销栈或正在进行的录制。
- 三维预览使用独立预览场景，不向用户当前场景创建地形或物体。文字标签是作者辅助；预览不等同于最终 Game View 可读性验收。
- 本次验收仅编译和自动测试；根据用户要求，没有使用 Computer use 或截图解析。

## 前三关修订（2026-09-25）

- L01：推开岩块到旗帜，参考解不改规则；拆掉 ROCK IS PUSH 后穿过也是合法另解，但不列入参考解。
- L02：拆开 ROCK IS STOP 后穿过岩块；通道顶盖为既有布局；当前全局规则已禁止登攀。
- L03：出生即 CLOUD IS YOU，参考解以 CLOUD 通关，不安排 ROBOT 到 CLOUD 的换控步骤。
- 三关均提供出生区域自动提示。运行时会把遮挡当前 YOU 的物体或地形变为半透明；透明只影响渲染，碰撞由核心规则决定。整片地形盒作为单个渲染对象，避免为大地图每一格生成对象。

设计参考采用 [Baba Is You 官方介绍](https://www.hempuli.com/baba/) 中“规则作为可移动物体，改变规则来改变对象行为”的原则；本项目的操作、关卡目标及控制对象以用户本次确认为准。

## 拖动复制与放置预览（2026-09-26）

- 使用“选择 / 框选”工具，在二维或三维点击物体、词牌或地形表面格。地形按格选择，保留原来的外观。
- Ctrl（macOS 为 Command）拖动可框选当前高度层的多格内容；Ctrl 点击追加对象或地形。二维可直接拖空白区域框选。
- 拖动选中内容移动整组；按住 Shift 再左键拖动，保留原件并在目标位置生成整组副本。复制会生成新实体 ID，选中状态转到新副本。
- 两个视图同步显示半透明落点预览；青色表示可放置，红色表示越界或冲突。松开鼠标才提交，Esc 或在画布外松开取消，整次移动/复制只占一个撤销步骤。
- 三维拖动固定在起点所在的水平层，避免鼠标掠过其他物体时落点高度跳变。跨高度可使用选区的 Y 轴移动手柄，也可使用右侧“整组偏移 / 复制”。

“地图大小”面板中的“自动填满底层地板”按当前已应用的地图边界，在最低 Y 层补齐石质地板。已有地形及外观保留，若底层存在实体则整次取消并提示冲突；支持一次撤销。尺寸有待应用修改时，先应用或取消后再填充。

## 基础编辑效率（2026-09-26）

- 画布上方的“地形 / 物体 / 词牌”控制点选、框选、吸管、擦除和删除的有效类别；“全部”恢复全选，“仅此”只保留对应类别。取消类别立即清理该类选区。被过滤内容继续显示，但不阻挡对后方有效内容的拾取。过滤不修改草稿、不占撤销记录。
- “擦除 [E]”删除笔画经过格中的已勾选且未锁定内容，包含地形；一次笔画一次撤销。地形笔刷的“挖除地形”也要求勾选地形。全部类别关闭时，选取、吸管、擦除停用，放置仍按当前笔刷执行。
- “吸管 [R]”可从二维或三维单格取得地形外观、物体初始名词或词牌 token，随后自动切到对应绘制工具。同格有多个候选时通过菜单选择；空白保持吸管。不会复制 ID、运行时性质、教学或参考解；随后放置生成新 ID。
- 画布取得输入焦点后：V 选择，B 地形笔刷，G 地形长方体，Q 物体，T 词牌，E 擦除，R 吸管，Shift+E / Delete / Backspace 删除有效选区，F 聚焦两侧画布，Shift+F 显示全图，Esc 取消预览。文本输入及试玩不触发这些编辑快捷键；拖动期间仅响应 Esc。保存用 Ctrl+S，撤销用 Ctrl+Z，重做用 Ctrl+Shift+Z；移除 O、I、Home、Ctrl+Y 的旧编辑绑定，Delete 和 Backspace 保留为删除选区的兼容键。试玩按键保持原有操作。
- 二维全图按实际画布宽高与地图 X/Z 尺寸适配，64×64 平面也能显示完整。全图模式随窗口和双视图比例变化重新适配；手动平移或缩放退出自动适配，Shift+F 可恢复。
- F 聚焦实体与地形选区的完整包围盒，保留三维观察方向；选区没有当前 Y 层内容时切到最低选中 Y。方块文字按内部区域自适应字号，完整名称在 9 号字仍放不下时显示前三字母，仍放不下再显示首尾两字母（如 ROCK → ROC → RK、ROBOT → ROB → RT）；IS 等短词保留原文。两字母在 8 号字仍放不下时隐藏文字。文字保持黑色并限制在块内，拖动预览同样处理，悬停仍显示完整名称。
- 类别、笔刷、视图与选区等编辑器状态随脚本重载恢复；这些状态不写入关卡 JSON。仍使用 Shift 拖动复制，不提供剪贴板复制粘贴。

三维方块使用表面描边：合并地形盒按世界整数格显示分界，便于分辨相邻格和高度层；物体、词牌及 WALL 栏杆部件描出各自外缘，透明隔墙显示格线。普通描边遵守深度遮挡，拖动预览保留半透明提示。此效果仅用于编辑器预览。

## 单格占用与物体笔刷

- 地图编辑初态中，一个三维整数格只能有一个可见方块：物体、词牌、石质地形、透明隔墙彼此不能重叠，同类方块也不能重叠。筛选类别和编辑锁定不会使已有方块失去占位。
- 点放、连续绘制、地形长方体、句子、移动和复制均检查占位。发生冲突时整次操作取消，草稿及撤销记录不变；整组移动可以使用本组同时腾出的原格。自动填地板继续只补空缺，不重复生成已有地形。
- “物体笔刷 [Q]”选定名词后，按住左键拖动可连续绘制；二维和三维共用轨迹，每个经过格最多一个物体，每个新物体具有独立 ID。半透明预览覆盖整条笔画，红色表示不能提交；松开提交整条笔画，一次撤销全部恢复，Esc 取消。
- 旧草稿可以打开并删除或移开冲突内容；重叠会列为地图错误，修正前不可保存或开始试玩。教学区域等辅助框不属于可见方块，不占格。
- 此限制针对编辑初态，不改变游戏运行中的规则穿透、同格接触和胜利判定。

## 三维三轴移动手柄

- “选择 / 框选 [V]”选中实体或地形后，三维选区中心显示 X（红）、Y（绿）、Z（蓝）箭头。拖动箭头只改变该轴，坐标按整数格吸附；可向箭头反方向拖动。
- 支持物体、词牌、地形及混合组选区；按住 Shift 开始拖动可沿轴复制。锁定和被过滤的内容不参与手柄变换。
- Y 轴拖动可跨层，二维显示层随偏移更新。半透明目标预览沿用青色有效 / 红色冲突提示；松开提交整次操作，一次撤销恢复。Esc、失去窗口焦点或在三维画布外松开取消，原层恢复；重叠或越界不提交。
- 摄像机旋转后仍按世界 X/Y/Z 约束移动。接近侧视导致两个轴投影同向时，箭头端点错开，可直接点选各自箭头。原有直接拖动的水平移动方式保留。
