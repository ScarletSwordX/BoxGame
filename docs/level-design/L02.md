## 1. 定位与教学目的

- 序列位置 / 前后关：第二关，承接 [L01](L01.md) 的移动、推动文字、拆句与重组规则。用户告知 L01 正在并行搭建；本卡不把其教学设计视为已经盲测通过。后续关卡命题待定。
- 关卡作用：首次教授控制对象可变，并用已有规则的空间与操作顺序挑战检验理解。换控是主认知，旧规则操作为它提供用途与验收场景；本轮新增 BOUNCY 作为次级新机制，其学习成本必须单独记录。
- 前置知识与学习位置：L01 中的移动、方向键推动文字（当前项目已移除 Shift 推动要求）、有效句子产生规则、拆句使规则失效、STOP 阻挡与 WIN 获胜，以及失控时 Z 撤销的全局反馈。玩家可能通过 FLAG IS WIN 另解完成 L01，因此不能假定他已亲自发现 WALL IS WIN。推动普通物件所需的 PUSH 属性也不是已被 L01 教过的内容。
- 核心新认知：YOU 决定当前控制谁；ROBOT 只是可能被控制的一种物件，控制权可以通过改写规则交给另一个已经存在的物件。
- 学习结果（建议）：已掌握 L01 规则操作的玩家，在当前角色无法到达所需操作位置时，能主动改写 YOU 的归属，控制另一物件继续推动文字或改变通路，并解释输入为何转移到它身上。
- 可观察的成功行为：能识别当前 YOU；通过自己的合法操作完成至少一次控制转移；换控后主动使用新物件的位置解决原先的站位问题；继续独立完成拆句/组句与获胜任务。仅开场操纵非 ROBOT 或碰巧切换一次，不能单独证明掌握换控。
- 预期误解：ROBOT 永远是主角；非 ROBOT 只是箱子或装饰；YOU 词牌只能与 ROBOT 配对；换控就是把机器人变形或瞬移；删掉所有 YOU 后还能继续走去拼新句子；用新角色走几步就算理解了换控用途。
- 本关不承担的新知识（建议）：同时控制多个对象、名词变形、HOVER/FLY、连续精确弹跳或复杂空中操作、新的箱子入点胜利条件。BOUNCY 与逐阶段的简单竖向路线纳入本轮方案，不假定玩家已掌握。若后续确需 PUSH，必须补教学依据，不能隐含为“经典推箱子大家都会”。P2 的弹性从 SPRING 转给 ROCK 属于旧句法的新应用，须观察是否形成新的物种误解。
- 目标体验时长 / 难度依据（待试玩校准）：原 v0.1 暂以首次 3—6 分钟作为设计假设；加入 BOUNCY 后需要重新观察，不据此硬性限时。比 L01 增加“我应该控制谁、何时交接”的一层决策，挑战主要来自可达站位和先后关系，不以更多箱子或更长搬运充当难度。

### 1.1 两个目标的分工

| 用户目标 | 本关设计落点 | 不能用来代替的证据 |
|---|---|---|
| 打破玩家必须是 ROBOT 的固有观念 | 把 YOU 的可变归属做成玩家主动使用的解题手段；控制另一既有物件后，从它的位置继续行动 | 仅换一个开场皮肤，或靠脚本强制切换控制对象 |
| 对已学规则做挑战验证 | 在旧 STOP/WIN 与文字推移的规则内，安排站位、退路或操作顺序的选择；让换控解决其中一个必要问题 | 新增一批属性词、复杂搬运，或给出完整解法让玩家照做 |

核心问题（用户已采用的方向，不是已定布局）：**“机器人走不到需要操作的位置时，能不能让别处的物件成为 YOU？”**

预期认知变化：ROBOT 是固定主角 → 当前有效的 YOU 句子决定谁响应输入 → 我可以先安排规则和位置，再把行动交给合适的物件。

### 1.2 挑战内容的优先选择

| 结构候选 | 可借鉴的空间问题 | 对本项目的改写方向 | 本工序建议 |
|---|---|---|---|
| 推动侧不可达 / 换控接力 | 目标格看似空着，但当前角色到不了推动侧 | 让另一个现有物件获得 YOU，从它已有的位置接续操作 | 优先；能直接体现换控的必要性 |
| 临时让位与操作顺序 | 过早把东西放到最终位置，会堵住后续通路或站位 | 先安排词牌位置和退路，再交接 YOU；复用拆句/组句 | 作为后续检验候选，先避免多重依赖 |
| 角落或窄道困局 | 只会继续推会把局面推死，需要保留回身位置 | 观察换控是否改变可达站位；明确它不会凭空增加拉取能力 | 暂不作为第一次换控的主难点 |

以上是针对本项目提出的结构候选，不声称已经复刻或验证某一款游戏的具体关卡；工序 1 不决定箱子数、阶段数或坐标；当前工序 2 的预算建议见下节。

优先让已学过的世界词牌承担可推方块的作用。选择受控新物种时，可从项目已有、没有额外运动特性的物种中挑选单个实例；本轮建议采用单个 ROCK，便于将换控目标与 SPRING 弹台区分；具体物种尚为提案。不能默认所有 WALL 同时变 YOU，也不能假定新物件有未写出的 PUSH 或穿墙能力。

### 1.3 学习验收与绕解判断

- 新认知的教学验收应包含一次由玩家主动促成的控制转移，并在后续未给解法指示的任务中独立使用；Teach–Test–Twist 不再作为本关制作门禁，留待最终多关卡联合审核。
- 换控必须改变可执行的操作或可达站位，不是“按一次指定步骤开门”的仪式。
- 整个挑战若可一直操纵 ROBOT 通关，应检查是否绕开本关核心教学。处理方式是回到布局/目标设计，不在游戏里加“必须换控才准赢”的隐藏计数。
- 换控后存在不同合法解可以保留；分别记录它们覆盖了哪些旧规则与新认知。不能把一条参考解的通过当成所有路径都学会。
- 试玩结束后询问“刚才为何开始控制另一个物件、它的位置解决了什么问题”，结合操作行为判断理解，不在解题前用问题泄露答案。
- 全局 NoControl → Z 撤销提示继续适用。L02 是否完全不设关卡提示尚未决定；L01 的 P2/P3 无提示要求不自动扩大成所有后续关卡的硬规则，工序 4 再具体设计。

### 1.4 与当前玩法的衔接约束

1. 这是控制转移，不是 ROBOT IS ROCK 的名词变形；原机器人与新受控物件是不同实例，输入从一个既有位置转到另一个既有位置。
2. 当前规格要求单 YOU；候选句子和同类物件数量必须避免同时产生多个可控对象。规则作用于全图同名物件，不按房间隔离。
3. 不能将“先拆掉唯一 YOU，失控后再走去拼另一条 YOU”设计成必需步骤。换控应在合法的一次操作结算中完成，或者在仍有唯一可控对象的前提下准备好交接。原型交接站位及实际回放见第 3 节，完整反例留工序 5 审查。
4. 第一关已经学过拆 STOP。若本关关键隔断也由可随手拆掉的 STOP 维持，要检查是否可绕过换控；固定 Terrain 与动态 WALL 的用途需在尺寸/逻辑工序明确。
5. 保持两个不同 YOU/WIN 实例合法同格的胜利合同；不照搬经典推箱子的“全部箱子占满目标点”判胜。
6. 本设计不依赖翻越；本轮读取到的 WorldModel 已禁止普通移动自动登攀。后续验证以届时运行版本为准，本卡不修改模拟。
7. 各阶段独立地图按设计延续固定结构、按作者快照重布物件/词牌；本关三阶段来自用户本轮建议，不构成其他关卡的默认数量。

## 2. 空间结构与地图尺寸

### 2.1 修订方向：三阶段分别形成完整挑战

v0.2 的单阶段连续链撤回，不将其中六个操作步骤包装成六个游玩阶段。按用户提出的顺序设计 P1—P3，各有初态、独立障碍、关键决策、目标和一次胜利。P1/P2 胜利后进入下一阶段固定初态，P3 胜利完成整关。

| 阶段 | 玩家要回答的问题 | 本阶段重点 | 获胜主体 |
|---|---|---|---|
| P1：使用弹性 | 如何借助下方的弹性物件到高处？ | 真实下落触发 BOUNCY，顶点横移到落点 | ROBOT |
| P2：转移弹性 | 旧弹簧位置不合适，如何让正确位置的物件获得弹性？ | 拆掉已有句子，搬运并重组属性；检查推动侧与操作顺序 | ROBOT |
| P3：转移控制 | 机器人到不了推动侧，但石头已在那里，谁可以来操作？ | 将 YOU 交给现有 ROCK，利用它的位置完成熟悉的规则操作 | ROCK |

这三个阶段按本关内容组织，不恢复逐关 Teach–Test–Twist 工序。P1 先建立弹跳经验，P2 用同一机制承载旧规则挑战，P3 再引入换控，避免把换控与弹跳的首次理解同时压给玩家。

### 2.2 P1：先使用已经生效的 BOUNCY

- 初态建议：ROBOT 在有支撑的中层入口；下方一个 SPRING；高处一个 FLAG。ROBOT IS YOU、SPRING IS STOP、SPRING IS BOUNCY、FLAG IS WIN 都已完整生效，真实词牌可读。首次使用不先安排缺词或交接句。
- 观察：目标高于当前行走平面；弹簧在可从上方落入的位置；上层落点在弹跳列旁边。
- 推理：平走够不到高处，尝试利用弹簧提供的竖向移动。
- 行动：走出平台边缘，真实下落到弹簧顶面；反弹至顶点后水平移动一格，到达高台并接触 FLAG。
- 独立挑战：理解入口、弹台、上升空间和落点的关系。只安排一次清晰的弹跳，不增加搬运或空中推字。
- 验收：记录真实下落、反弹与顶点横移；通关后能解释弹性来自规则。仅把模型画成弹簧不能证明玩家理解了 BOUNCY。
- 易错与恢复：侧撞弹簧不触发；方向选错可撤销。具体反馈和提示留工序 4，不预设强制文字讲解。

### 2.3 P2：拆掉旧句，把弹性用在正确的位置

- 初态建议：仍由 ROBOT 控制。保留 P1 的地形和地标，扩展新的操作区与目标台，旧目标移除或迁到新位置。一个 SPRING 仍有 STOP 和 BOUNCY；另一个 ROCK 已在通往新目标的正确弹跳位置，只有由世界句子提供的 STOP。
- 关键条件：只有一个 BOUNCY 词牌，初始属于 SPRING IS BOUNCY；ROCK IS 的待补句在可操作区域。ROBOT 能到达整个必要推动路线及 ROCK 的落入入口。
- 观察：旧弹簧仍可正常弹跳，但其顶点不能直接送到新的目标；处在正确位置的石块有实体表面，却没有弹性。
- 推理：弹性取决于句子中的属性，能否把旧弹簧的 BOUNCY 转给石块？
- 行动意图：从 SPRING 句中推走 BOUNCY，使旧弹性失效；将词牌搬到 ROCK IS 的句尾，组成 ROCK IS BOUNCY；再从入口落到石块顶面，弹向新目标并以 ROBOT 获胜。
- 规则结果：ROBOT IS YOU 不变；SPRING IS STOP、ROCK IS STOP 保留；BOUNCY 从 SPRING 转移到 ROCK。不要把受控角色改成 ROCK，也不使用名词变形。
- 独立挑战：判断哪个已成立的规则需要被拆掉，并把有限的规则材料重新用于正确位置。与 P1 的差别是玩家必须改造规则。
- 推箱结构：原型采用一格绕行柱与侧向站位支台；参考解先推动旧句，再沿右侧搬运 BOUNCY，最后从右向左组句。实际坐标与回放见第 3 节。
- 审查要求：拆掉旧弹性后仍能完成文字搬运和到达新弹台入口；不能把必经返程只留在刚被拆掉的弹跳路线上。新的目标不得从旧弹簧直接到达。源词移用及合法另解需单独检查。
- 验收：玩家主动拆旧句、重建新句，并用新弹台通关；观察其是否理解同一属性可作用于不同物种。

### 2.4 P3：操作办法已经会了，改变执行者

- 初态建议：ROBOT 出生在新增的控制台一侧；单个 ROCK 已在隔断另一侧的操作台上。FLAG 为本阶段新目标；弹跳路线沿用前面已建立的高度关系。
- 本阶段重布：ROCK 从 P2 的弹台位置重布到远端站位，P2 的 ROCK IS BOUNCY 不继承；ROCK IS STOP 源句保留在左上方同一位置，不影响单个 ROCK 获得 YOU。弹性操作重新落在 SPRING 上，初态有 SPRING IS STOP，但 SPRING IS BOUNCY 尚未成立。
- 观察：玩家已知道怎样补好弹性句、怎样使用弹跳；这次机器人无法到达缺词所需推动侧，ROCK 却已在那一侧。固定 Terrain 承担关键隔断。
