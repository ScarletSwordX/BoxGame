# 初始界面与暂停菜单

日期：2026-09-27

- 初始界面采用暖砂底色、淡紫按钮与三块规则词牌，保留 Rule Workshop、Play、Quit。启动时等待 Play 才建立关卡会话。
- Esc 或 HUD 的 Pause 打开暂停菜单；Resume 或 Esc 继续；两处 Quit 在独立游戏中退出应用，在 Unity 编辑器中停止播放。
- 暂停冻结操作、区域提示计时、移动动画、镜头过渡和地图展开。恢复保留会话与撤销记录；组件停用时恢复进入暂停前的时间倍率。
- 玩家菜单、HUD、正式目录六阶段名称与提示、失控提示、弹跳顶点提示均使用英文。PlayerText 在显示边界转换作者文案，不改动关卡文件；新增中文作者文案需添加英文条目，正式目录覆盖测试会检查遗漏。编辑器工具与设计文档保留中文。
- UIDocument 重建后重新绑定菜单回调，避免面板重新启用后按钮失效。
