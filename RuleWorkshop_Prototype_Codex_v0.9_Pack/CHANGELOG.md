# v0.8 → v0.9

## 用户最新约束
所有显式规则有世界词块；允许地形阻止接近部分词块，但不允许只读规则板提供规则。第一和第二关也必须遵守。

## 数据与解析
- 版本变为 schemaVersion=9 / RW-v0.9。
- 删除 fixedRules，以及 Parser 的列表规则注入路径。
- 原有只读句子逐词转换为实际 entities/Text，每个词有独立 ID、token、cell 和真实支撑。
- 全部 Text anchored=false；主区原来固定的名词/IS 也解锁。
- 全部隐式源区以透明固定 Terrain 与主区分隔，可读而不可直接到达；没有 isProtected 等推动特判。
- 新增每条性质和变形的 SourceTextIds 核查；所有来源必须是连续 +X/+Z 世界词。
- 修正历史词牌 ID 与 FLAG token 明显不符的命名；仍然必须以 token 为显示和语法来源。

## 关卡
- L01 重做：ROBOT IS YOU 是世界句子；推 WIN 补 FLAG IS WIN，再进入目标。
- L02 重做：推 PUSH 补 ROCK IS PUSH，再搬石搭阶。控制和目标规则也在世界。
- L03—L12 保留核心命题，但加入所有世界源词、解除主区锁词，并重跑全部参考路径。
- 全部十二关 requireActiveInteraction=true；互动仍只属于作者审核，不加入胜利公式。
- 保留十二关、十八条参考解、五个多策略关、ROBOT IS FLAG 变形和不同实例同格胜利。

## 作者工具与表现
- 移除固定规则输入列表；“放一句话”工具生成真实词牌，不保存后台规则。
- 必须检查 WorldState/TextView 数量、token 一致性、世界可读性和源词聚焦。
- 派生规则摘要可有，但不能取代世界词或创建规则。
