# v0.8 变更记录

## 用户授权的新机制
- 移除 v0.7 对名词变形的排除，加入任意已登记物种之间的 `IS` 原地转换。
- 保留十二关、L02起有效互动、至少四关机制不同的多解、不同实例同格胜利。

## 规则与数据
- Parser 输出属性规则和变形映射。Object.currentSubject 为运行中的可变状态，稳定 ID 不变。
- 转换持久、属性重算、全局源快照、每实例每指令一次。文字本体和固定地形不参与。
- 冲突不随机裁决：多目标、一变多、混合右侧、多YOU、非法实体同格须诊断。
- 胜利位于变形批次完成和合法性检查之后；快照恢复不重执行变形。
- schemaVersion 8，mechanicsVersion RW-v0.8，新增 transformationMode。

## 内容
- L01—L07、L09—L11 保留布局与参考操作，并在新模型复核。
- L08：原可动 WIN 词替换为 FLAG，B 解改为 ROCK IS FLAG；A 的推石登高路线保留。
- L12：岩块目标槽及原机器人目标槽的词改为 FLAG；换控目的类别由 FLAG 改为 SPRING。
- L12-C 重新编写为 11 条指令：先换控弹簧，再变形原机器人，最后进入原身体。
- 总数仍为12关、18条参考解、5个多策略关。未新增第13关。

## 程序与编辑器实施合同
- 增加 TransformationResolver、当前身份快照、全局变形结果预览、源句追踪。
- Renderer 区分属性变化（身份模型保留）与物种变化（实际换模型）。
- 扩充变形后的 YOU 数量、碰撞、重力、WIN配对预览与冲突报告。

## 验证
- 50项原有局部检查与30项变形局部检查，共80项。
- 18条参考解、整步撤销、实体顺序扰动和11个无互动子图已在本版重跑。
- 不声称 Unity 已完成，不沿用旧版本运行结果。
