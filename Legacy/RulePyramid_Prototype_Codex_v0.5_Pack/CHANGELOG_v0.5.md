# Prototype-v0.5 / RP-v0.5 变更记录

## 版本

完整替换最初的 Prototype-v0.1 实施合同，整合 LD-v0.4 的动作与胜利、Rules-v0.4.1 的默认规则。统一新 schemaVersion=5、mechanicsVersion=RP-v0.5，不靠同时运行多份补丁解释行为。

## 默认行为

- YOU 显式提供控制权，当前 YOU 默认实体；不摆冗余 RED IS BLOCK。
- 世界默认 Down，包含可动文字、非阻挡颜色和空心 WIN；不摆 RED IS FALL，不保留 FALL 词。
- HOVER 是零重力工作名，FLY 是上浮；动态常态优先级 FLY > HOVER > Down。
- 固定地形/锁定文字使用可見固定约束，不能由隐藏免重力复刻旧解。

## 操作与终局

- 保留四向走/文字链推、原地跳、单体顶起、条件落地压低。
- 没有自动登阶、地面定向跳、普通空中横移、独立 Pull 或 PUSH 词。
- JUMP 接触面将下落者从接触格向上弹三格；顶点一次侧移/恢复下降。
- 同格获胜、可进入空心目标、合法原子变化后即时判胜；没有邻接兜底。

## 六关

- L01 改为更小的同高绕行，保持目标语义。
- L02 全新落字成句，WIN 最终有真实地基支撑，不再顶高后悬停。
- L03 拆 BLUE IS HOVER 恢复默认下落并落成桥，不再添加 FALL。
- L04 保留三格弹跳主题，重排高台与文字，所有初始动态对象稳定。
- L05 沿用前后平台登乘命题，补 AND 最终位置的真实承托，移除冗余默认碑文。
- L06 保留两个接触基准高度；上层改为拆 PINK IS HOVER，让塔冠下降到可进入格。

## 框架与编辑器

保留纯 C# Core / Unity Runtime / Editor 分层，统一颜色/文字实体替代 Explorer/Goal；多实体格索引、属性来源、接触/阶段、事务撤销集中实现。关卡 DTO 改为普通对象/列表，不把紧凑六数嵌套数组直接作为 Unity 序列化合同。

编辑器增加默认来源、文字落稳、HOVER/FLY 覆盖、目标自格、三格弹跳与载人净空诊断；作者草稿与试玩隔离。边缘支撑仍只留接口，不改六关实际支撑策略。
